# Изменения

## 0.6.0
* Добавлен редактор текстов основных разделов страниц: главная, каталог, карточка товара, навигация, FAQ, политика данных, 404 и SEO-метаданные.
* Собственные тексты сохраняются в `settings.json` в `pageTexts`; пустые значения используют стандартный текст шаблона.
* Для поддержки редактора обновлены шаблоны сайта до версии 2.4.0.

## 0.5.0
* **Товары → прайсы.** Товары можно объединять в группы («Прайс_1», «Прайс_2»…): вкладки для переключения, создание (пустой или копия), переименование, дата прайса, удаление, копирование товара между прайсами. Кнопка «Разместить на сайте» выбирает прайс для публикации; внутри любого прайса работает прежнее редактирование (добавить, изменить, скрыть, порядок, дублировать, удалить, фото, SEO).
* Добавлен прайс ООО «Глауконит» на 1 февраля 2026 г. (из файла) — как «Прайс_2»; «Прайс_1» — текущий каталог, остаётся на сайте.
* **Контент сайта → тексты шапки и подвала**: любой текст можно заменить полностью; пустое поле = стандартный текст; «Взять стандартный и править», «Вернуть стандартный».
* **Контент сайта → контакты**: у каждого способа связи переключатель «показывается / скрыт на сайте». Скрытый контакт не проверяется и не блокирует выкладку; все контакты скрыть нельзя; предупреждение, если WhatsApp без номера подставит скрытый телефон.
* «Публикация» показывает смену прайса по ценам, скрытие/показ контактов и заменённые тексты.
* Переключатель «Кнопка „Скачать прайс-лист“ на сайте» (Контент сайта → Прайс-лист); проверка сборки следит, что файл прайса создан.
* Резервные копии охватывают и `pricelists.json`.
* Тесты: +29 (прайсы, контакты, тексты); для запуска без папки сайта добавлена встроенная фикстура `tests/fixture-site`.

## 0.4.0
* Переход на `products.json` / `settings.json` сайта как единственный источник данных (SQLite убран).
* Новые разделы: «Контент сайта», «Публикация», «Настройки → Сервер».
* Выкладка на VPS по SSH релизами с откатом, проверкой отпечатка сервера и проверкой сайта после выкладки.
* Проверки перед выкладкой: ошибки данных, заглушки контактов, дата прайса, тяжёлые изображения, сборка не для того адреса / с noindex.
* Редактор товара: все поля сайта, загрузка и выбор фото, автоматический slug с редиректом при смене, предпросмотр поисковой выдачи.
* Резервные копии перед каждой записью и восстановление; журнал действий.
* Electron обновлён, окно в sandbox, строгая CSP.
