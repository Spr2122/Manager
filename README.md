# SorbentOpt Manager 0.6

Настольное приложение для управления сайтом СорбентОпт: **товары и цены → редактирование текстов страниц → контакты и реквизиты → проверка → сборка → выкладка на ваш VPS**.
Работает с локальной копией сайта; в интернет ходит только на ваш сервер (по SSH) и для проверки, что сайт открылся.

## Запуск

* Нужен [Node.js LTS](https://nodejs.org/).
* `install-and-start.bat` — установит всё нужное и запустит приложение.
* `build-installer.bat` — соберёт установщик для Windows (папка `release`).
* Для разработки: `npm run dev`; проверки: `npm run typecheck`, `npm test`.

## Как работать

1. **Первый запуск**: выберите папку сайта (в ней `package.json` и `src/data/products.json`).
2. **Настройки → Сервер**: адрес VPS, пользователь `deploy`, «Создать SSH-ключ», добавить публичный ключ на сервер, «Проверить подключение», сверить отпечаток. Подготовка сервера описана в `DEPLOY.md` сайта.
3. **Контент сайта**: можно менять тексты шапки и подвала, контакты и реквизиты. В блоке «Тексты разделов страниц» редактируются заголовки, описания, карточки применения и преимуществ, вопросы и ответы, подписи кнопок, тексты страницы политики данных, страницы 404 и SEO-заголовки/описания. Пустое поле означает стандартный текст. Тексты товаров редактируются во вкладке «Товары».
   **Важно:** редактор разделов работает с сайтом версии 2.4.0 или новее, где шаблоны подключают поля `pageTexts` из `src/data/settings.json`. Используйте совместный архив сайта v2.4, приложенный к этой версии менеджера.
4. **Товары**: товары собраны в прайсы («Прайс_1», «Прайс_2»…). Вкладки сверху переключают прайс, кнопка «Разместить на сайте» выбирает, какой из них увидят посетители. Внутри каждого прайса редактирование такое же, как раньше. Правки сохраняются сразу, перед каждой записью делается резервная копия.
5. **Публикация**: проверка → «Собрать сайт» → «Предпросмотр» → «Выложить на сайт». Откат — в блоке «Версии на сервере».

## Что нового в 0.6

* Добавлен редактор текстов основных разделов страниц: заголовки и описания главной, карточки применения и преимуществ, технический блок, FAQ, разделы документов и доставки, контакты, каталог, страница товара, политика обработки данных, 404, навигация и SEO title/description.
* Пустое поле возвращает стандартный текст; свои тексты сохраняются в `settings.json` в объекте `pageTexts`.
* Совместим с сайтом версии 2.4.0 и новее. Тексты товаров по-прежнему редактируются в карточке товара.

## Что изменилось по сравнению с 0.3

| Было | Стало |
|---|---|
| Данные в SQLite, перенос в `products.ts` разбором кода | Данные лежат прямо в `products.json` сайта — один источник правды, нечего синхронизировать |
| Цена превращалась в число и ломала сборку сайта | Цена — число (`null` = «По запросу»), форматируется на сайте; сборка проверяет данные |
| Не было `shortName`, `minimum` | Все поля сайта редактируются |
| SEO-поля ничего не делали | Реально попадают в title/description страницы, есть предпросмотр поисковой выдачи |
| Смена slug создавала дубли и ломала ссылки | Старый адрес автоматически перенаправляется на новый |
| Скрыть товар было нельзя | Статус «черновик» полностью убирает товар с сайта |
| Выкладки не было | Сборка, проверка результата, загрузка по SSH «релизами», атомарное переключение, откат, проверка сайта |
| Заглушки контактов оставались незамеченными | Приложение не даст выложить сайт с заглушками и предупредит о дате прайса |

## Устройство

```
src/shared     общая логика без Electron: типы, цены, slug, проверки данных, сравнение с прошлой выкладкой
src/main       основной процесс: файлы сайта, запуск сборки, SSH/SFTP, выкладка релизами, конфиг и секреты
src/preload    мост между интерфейсом и основным процессом (только перечисленные в Api методы)
src/renderer   интерфейс (React)
tests          84 теста: логика каталога, хранилище, выкладка (настоящие ln/mv/rm), SSH против тестового сервера
```

Безопасность: окно в `sandbox` без Node.js, строгая CSP, навигация и новые окна запрещены, обмен только через типизированный `Api`
с проверкой источника; пути ограничены папкой `public/`; отпечаток сервера запоминается и проверяется; пароли — в защищённом хранилище ОС
(`safeStorage`); на сервер выполняются только команды из фиксированного набора с экранированием путей.

Служебные файлы приложения лежат в папке `.manager/` внутри сайта (резервные копии, журнал, состояние сборки и выкладки) — в Git она не попадает.

## Прайсы (группы товаров)

* Данные всех прайсов лежат в `src/data/pricelists.json`. **Сайт его не читает**: прайс, выбранный «на сайте», автоматически копируется в `src/data/products.json` — формат этого файла не изменился.
* При первом запуске 0.5 текущий каталог становится «Прайс_1» (он остаётся на сайте), рядом создаётся «Прайс_2» — прайс ООО «Глауконит» на 1 февраля 2026 г. из файла `Прайс_ОООГлауконит_2026.docx`. Карточки товаров (описания, фото, SEO) берутся из текущего каталога, меняются только цены; позиции без цены в файле получают «По запросу».
* «Разместить на сайте» подставляет дату прайса в «Контент сайта → Дата прайса» (если у прайса она указана). После этого — «Публикация»: проверка → сборка → выкладка.
* Товары между прайсами можно копировать (значок рядом с «Дублировать»); новый прайс можно начать как копию существующего.
* Если `products.json` изменить вручную, активный прайс подхватит эти изменения.

## Контакты, шапка и подвал

В `settings.json` появились два **необязательных** поля. Пока ими не пользуются, в файл они не пишутся.

```jsonc
{
  "hiddenContacts": ["max", "telegram"],      // 'phone' | 'telegram' | 'whatsapp' | 'max' | 'email' — не показывать на сайте
  "texts": {                                  // пусто/нет ключа = стандартный текст сайта
    "headerBrand": "", "headerTagline": "", "headerCta": "",
    "footerBrand": "", "footerTagline": "", "footerAbout": "", "footerRequisites": "",
    "footerDisclaimer": "", "footerCopyright": "", "footerPolicyLabel": ""
  }
}
```

**Сайт версии 2.1 и новее эти поля читает** (`src/data/site.ts`). На более старой версии сайта скрытие контактов и свои тексты не сработают. Многострочные значения (`footerRequisites`) выводятся с переносами строк; значения — обычный текст, не HTML.
Скрытый контакт не проверяется приложением и не считается заглушкой при выкладке; скрыть все контакты нельзя.

## Кнопка «Скачать прайс-лист»

Сайт 2.1+ собирает Excel-файл `price/sorbentopt-price-list.xlsx` из товаров, цен и даты выбранного прайса (опубликованные товары; «По запросу» для товаров без цены; только показываемые контакты). Кнопка стоит под ценами на главной, в каталоге и на странице товара. Выключается в «Контент сайта → Прайс-лист» (поле `priceDownload: false` в `settings.json`; по умолчанию включено). Если у сайта есть страница прайса, а в сборке файла нет, проверка сборки покажет ошибку.
